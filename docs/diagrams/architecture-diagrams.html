3. Flujo CRUD Completo (Crear Registro)

Desde el click en "Agregar" hasta que el dato queda en Firestore con audit log

sequenceDiagram actor U as Usuario participant P as ModulePageLayout participant H as useCrudModule participant A as useApiClient participant R as API Route /POST participant V as Zod Validation participant FR as Firestore Repo participant FS as Cloud Firestore participant CF as Cloud Functions U->>P: Click "Agregar" → Abre FormDrawer U->>P: Completa formulario → Submit P->>H: create(formData) H->>A: post("/api/tenders", formData) A->>R: HTTP POST + Bearer Token R->>R: getTenantContext() – Valida token y rol R->>V: createSchema.parse(body) V-->>R: Datos validados (o error 400) R->>FR: createEntity(tenantId, "tenders", data, actor) FR->>FS: SET /tenants/{tid}/tenders/{uuid} FS-->>FR: OK FR-->>R: Tender creado { id, ...data } R-->>A: 201 { data: Tender } A-->>H: Response H->>A: get("/api/tenders") – Recarga lista H-->>P: items actualizados P->>U: Toast "Licitación creada" + Cierra drawer Note over FS,CF: Async (trigger) FS->>CF: onDocumentWritten CF->>FS: Crea AuditLogEntry

4. Flujo DELETE con Confirmación

Proceso de eliminación segura con diálogo de confirmación antes de actuar

sequenceDiagram actor U as Usuario participant P as ModulePageLayout participant CD as ConfirmDialog participant H as useCrudModule participant A as useApiClient participant R as API Route /DELETE participant FR as Firestore Repo participant FS as Cloud Firestore U->>P: Click botón "✕" en fila de la tabla P->>CD: Abre ConfirmDialog CD->>U: "¿Seguro que desea eliminar este registro?" alt Usuario confirma U->>CD: Click "Eliminar" CD->>P: onConfirm() P->>H: remove(id) H->>A: delete("/api/tenders?id=xxx") A->>R: HTTP DELETE + Bearer Token R->>R: getTenantContext() – write access R->>FR: deleteEntity(tenantId, "tenders", id) FR->>FS: Verifica existencia del doc FR->>FS: DELETE doc FS-->>FR: OK FR-->>R: void R-->>A: 200 { ok: true } A-->>H: OK H->>H: reload() – Recarga lista H-->>P: items actualizados P->>U: Toast "Eliminado exitosamente" else Usuario cancela U->>CD: Click "Cancelar" CD->>P: onCancel() P->>U: Cierra diálogo, sin cambios end
